# PARKOUR-ARANHA
Prepare-se para desafiar a gravidade no Parkour Aranha! Enfrente 100 níveis progressivos em cenários cibernéticos ultra 4K. Combine saltos duplos, mortais acrobáticos, corridas pelas paredes e impulsos no ar com disparos de teia para alcançar o portal final. Escolha entre 3 dificuldades e domine o movimento 360° no topo das alturas!
